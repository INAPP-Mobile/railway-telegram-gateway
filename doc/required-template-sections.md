# Deploy and Host\n\nYou can deploy this template directly to [Railway](https://railway.app/) via the "Deploy on Railway" button. The platform handles all infrastructure provisioning and environment variable management.\n\n## About Hosting\n\nThis gateway is designed to run on managed hosting platforms like Railway. It uses a single-node architecture by default but scales horizontally across connected WebSocket clients.\n\n## Why Deploy\n\n- **Zero-config Bot Routing**: Automatically registers webhooks with Telegram when using the Admin API.\n- **Multi-Bot Support**: Manage unlimited bot deployments from a single service instance.\n- **Instant Scaling**: Handle traffic spikes through standard WebSocket client subscriptions without complex load balancing.\n\n## Common Use Cases\n\n1. **Bot Aggregation Layer**: Forward multiple bot updates to external services (e.g., monitoring, logging backends).\n2. **Real-time Bot Dashboard**: Build a live dashboard showing active messages across multiple Telegram bots in real-time.\n3. **Webhook-to-Internal-API Conversion**: Convert standard webhooks to real-time streams for frontend applications that require low-latency updates.\n\n## Dependencies for\n\n### Deployment Dependencies\nThis project requires:\n- **Node.js** version 18 or higher (for Vite/Esl support).\n- A valid **Telegram Bot Token** (via the service's Admin API) to enable webhook registration for each bot.\n- **GATEWAY_API_KEY**: Environment variable to secure WebSocket and Admin routes.
